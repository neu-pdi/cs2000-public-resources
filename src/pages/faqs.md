# FAQs

## Skills
### Can I retake a skill?
You can retake a given skill up to 4 times during the semester (plus possibly an extra during our final), *as long as the skill is still available*! We encourage you to take a skill as many times as you feel would be helpful, and we won't penalize you for taking a skill more than once.

### Can I retake a skill after it is no longer available?
During our final exam period, you can retake up to 2 distinct skills (only one attempt _per skill_).

### When will I see my skill scores?
The TAs work hard to get skills graded as fast as we can. We always try to have skills graded within a week (often sooner). Keep in mind, some skills may get done sooner than others. Don't worry, it just means the other skills have not been graded yet.

### Can I review a skill I already took?
Reviews of skills you have already took must be done **in person**, not online. You can do this during a professor's office hours, or after you complete a lab, should the TAs be available. You cannot take pictures of a skill (graded or ungraded).

### I don't agree with a grade I got, what do I do?
Check out our [regrade request policy](/syllabus/#regrade-requests) for info on how to submit a regrade request for a skill. You will have 7 days to do so.

## Assignments
### When are assignments due?
Each assignment is due at its [Assignment Crit](/syllabus/#assignment-crits), in lab every other Friday: the calendar and the assignment's page give the date. Be sure to complete all work before the Assignment Crit, as you will present your project at that point.

### How are assignments graded?
Assignments are graded based on the [Assignment Crits](/syllabus/#assignment-crits), which occur during lab.

### I don't agree with a grade I got, what do I do?
Assignment Crits have no regrades, since they are based on the feedback of the panel that saw the presentation. However, by going to class, you can essentially bring up this grade (see [Grading](/syllabus/#grading)).

## VS Code
### When trying to edit a file, no run button is showing
The **PLL: Run Python File** button only appears for files whose names end in `.py`. If you are editing a `.py` file and still don't see it, you can run it from the Command Palette (`Ctrl+Shift+P` on Windows, `Cmd+Shift+P` on a Mac) with **PLL: Run Python File**. If that doesn't work either, try the following to fix the issue:
1) Uninstall the Python Language Levels (PLL) extension
2) Restart VS Code
3) Re-install the Python Language Levels (PLL) extension

If the issue continues, let us know in the Discord
