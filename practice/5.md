## Working with Lists

Here's some cafe sales data:

```python
cafe_data = table(
    ["day", "drinks-sold"],
    [
        ["Mon", 45],
        ["Tue", 30],
        ["Wed", 55],
        ["Thu", 40],
        ["Fri", 60],
    ],
)
```

### Extracting Lists from Tables

Extract the drinks-sold column as a list using `.column`. What does this list look like? How is it different from the original table?

### Mathematical Operations on Lists

`max`, `min`, and `sum` are built in, but you'll need to import the statistics library:

```python
import statistics as S
```

Using the extracted list, find:

- The maximum number of drinks sold (use `max`)
- The minimum number of drinks sold (use `min`)
- The average daily sales (use `S.mean`)
- The total weekly sales (use `sum`)

### Creating List Literals

- A list of test scores: 85, 92, 78, 96, 88, 91

Using your test scores list, calculate:

- The highest score (use `max`)
