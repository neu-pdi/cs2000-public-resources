## Working with for Loops

To define our own list processing functions, we need a way to do computations for each element in the list. We'll use iteration with `for` loops.

This requires being able to change the value of variables, which PLL allows inside functions at `#level intermediate` (so that should be the first line of your file).

**Pattern is:**

```python
def my_function(my_list: list) -> ...:
    my_var = initial_value
    for my_elt in my_list:
        # CODE IMPLEMENTATION HERE
    return my_var  # Final result
```

**Example:** while `sum` is built in, we could have defined it ourselves as:

```python
def my_sum(num_list: list[float]) -> float:
    total = 0
    for n in num_list:
        total = total + n
    return total

def test_my_sum():
    assert my_sum([0, 1, 2, 3]) == 6
```
