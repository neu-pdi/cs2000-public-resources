### Computing New Columns

Let's add the total cost of each order, accounting for discounts. We start with
the price without discounts, a straightforward use of lifting:

```python
TICKET_PRICE = 10.0
events["total"] = events["numtix"] * TICKET_PRICE
```

Try giving a 10% discount to everyone with the `"birthday"` code. We create a
mask for it, then update just those rows:

```python
bday_mask = events["discount"] == "birthday"
events.loc[bday_mask, "total"] = events["total"] * 0.90
```

The notation for computing a new column and for updating an existing one is the
same (unlike PLL's separate `add_column` and `transform_column`): pandas creates
the column if the DataFrame doesn't have one with that name, and otherwise
updates it.

### Aggregating and Grouping Columns

Pandas has built-in operations for computations over a Series, like PLL's
`t.sum("numtix")` and `t.mean("numtix")`:

```python
events["numtix"].sum()    # total number of tickets sold
events["numtix"].mean()   # average number of tickets per order
```

What if we want the total for each discount code? We could filter the table to
each code and sum each result, as we would with PLL tables, but that's a lot of
work, and summarizing one column around the values of another is common in data
analysis (spreadsheets call it a "pivot table"). In pandas, we use `groupby`:

```python
events.groupby("discount").count()           # how many orders had each code
events.groupby("discount")["numtix"].sum()   # tickets sold with each code
```

`groupby` takes the column whose values are used to group the rows, and
returns a `GroupBy`, on which we can select a column and do an operation, for
each group of rows. The second expression produces a Series labeled by discount
code, showing that 14 tickets were bought with no code (`""`), 2 with
`"birthday"`, and 8 with `"student"`. The pandas documentation lists many more
operations on `GroupBy` data, such as means and other statistics.

## Intro (15 mins)

Today we learn Pandas operations that correspond to what you learned with PLL tables: filtering tables, sorting, and adding/transforming columns.

### Filtering rows (like PLL's `filter`)

```python
# PLL way:
# def is_high_value(r: dict) -> bool:
#     return r["amount"] >= 5.0
# high_orders = orders.filter(is_high_value)

# Pandas way -- we construct "masks" that look like boolean expressions, but 
# refers to an entire column (i.e., Series).
high_orders = orders[orders['quantity'] >= 2]
takeout_orders = orders[orders['order_type'] == 'takeout']
```

### Sorting tables (like PLL's `order_by`)

```python
# PLL way:
# orders.order_by("quantity", ascending=True)   # ascending
# orders.order_by("quantity", ascending=False)  # descending

# Pandas way:
orders.sort_values('quantity')                    # ascending
orders.sort_values('quantity', ascending=False)   # descending
```

### Adding new columns (like PLL's `add_column`)

```python
# PLL way:
# def calc_total(r: dict) -> float:
#     return r["quantity"] * prices[r["dish"]]
# orders_with_total = orders.add_column("total", calc_total)

# Pandas way -- we _assign_ to a new column (here 'total') and construct it 
# by applying a function (here a `lambda`) that is passed a row.
prices = {'Pasta': 12.0, 'Salad': 8.0, 'Burger': 10.0}
orders['total'] = orders.apply(lambda row: row['quantity'] * prices.get(row['dish'], 0), axis=1)
```

### Transforming existing columns (like PLL's `transform_column`)

```python
# PLL way:
# def discount_price(price: float) -> float:
#     return price * 0.9
# discounted = orders.transform_column("total", discount_price)

# Pandas way -- here, we similarly assign to a column, but this time 
# an existing one. But to create it, we again use `.apply` with a function, 
# but here on a single column (Series), so the function is over the single 
# values, rather than the entire row. We could transform an existing column using the
# entire row (something not possible with PLL's transform_column) by using 
# `orders.apply(lambda row: ...)` as above.
orders['total'] = orders['total'].apply(lambda price: price * 0.9)
```

## Wrap-up (5 mins)

- Pandas provides the same table operations you learned with PLL tables: filtering with boolean conditions, sorting by columns, adding new columns with computations, and transforming existing columns.
- The syntax is different (boolean masks vs functions, `.sort_values()` vs `.order_by()`), but the concepts and capabilities are the same.
