### Mutating Variables in Memory

On [Day 15](/days/15), we used a variable to add up the elements of a list.
Here it is again, at the top level of the file (so it needs `#level advanced`):

```python
#level advanced

total = 0
for num in [5, 1, 7, 3]:
    total = total + num
```

Let's see how the program directory changes as this runs. Basic data (numbers,
strings, booleans) have no internal structure, so they are stored right in the
directory. (Structured data, such as lists, are stored in a separate place
called the _heap_, which we'll cover on [Day 25](/days/25).) So the first line
puts `total` in the directory:

```
total  0
```

The `for` loop also sets up a directory entry, for the name we chose for the
list elements, `num`. When the loop starts, `num` is the first element:

```
total  0
num    5
```

Inside the loop, the `=` tells Python to change the value of `total`. Since
`total` is a number, this changes its entry in the directory:

```
total  5
num    5
```

Python then advances `num` to the next element (`1`), changes `total` to `6`,
and so on, until every element has been processed. When the loop ends, the
directory contains:

```
total  16
num    3
```

There are two takeaways from this example:

- When we use `=` to update a variable, the variable's entry in the directory
  changes to reflect the new value.
- A `for` loop introduces a name into the directory (the one we chose for the
  elements), and as the loop goes on, updates it to each element in turn.

## Intro (15 mins)

- Today we explore how variable assignment, mutability, and scoping work in Python. Since today's examples change variables at the top level of the file, and use `global`, use `#level advanced`.

### Assignment and Scoping
  ```python
  x = 10
  x = 20  # x is now 20 -- all variables are mutable

  y = 5
  y = y + 2  # y is now 7

  # Scoping example:
  y = 20
  def f():
      y = 30  # This is a new local y, does not affect global y
      return y
  print(f())  # prints 30
  print(y)    # prints 20

  # Using global keyword:
  z = 100
  def g():
      global z # Now `z` within function is same as `z` at top level
      z = 200
  g()
  print(z)    # prints 200
  ```

## Wrap-up (5 mins)

- Python's rules for assignment and scoping determine which variable each use of a name refers to.
- Understanding these rules helps avoid bugs and write clearer code.
