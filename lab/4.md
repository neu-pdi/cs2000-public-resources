## Location Tags

A location tag is a small device that nearby phones detect, and report to the
tag's owner, so that a lost bag or set of keys can be found.

```python
# A TagId is a str: a tag's unique identifier.
# A Time is an int: the number of seconds since Jan 1, 2025.

@dataclass
class OwnTagEncounter:
    tagid: str
    time: int

@dataclass
class OtherTagEncounter:
    tagid: str
    time: int

# An Encounter is a record of your phone seeing a tag: an OwnTagEncounter if
# the tag is yours, and an OtherTagEncounter if it isn't.
Encounter = OwnTagEncounter | OtherTagEncounter

encounter_1 = OwnTagEncounter("t1", 10)
encounter_2 = OwnTagEncounter("t1", 20)
encounter_3 = OtherTagEncounter("t2", 30)
```

Problems 1 to 3 each take a `list[Encounter]`: design each with the list
template (`case []` and `case [f, *r]`, as in [Class 22](/class/22)) or a `for`
loop, and try both on at least one of them.

## Problem 4

Location tags can be used to stalk someone: a tag hidden in a person's car or
bag reports where they go. Tags now have some protections: they beep when
they've been away from their owner long enough (though the speaker can be
removed), and phones can warn a non-owner that a tag is traveling with them.
But these came well after the tags were sold, and after lawsuits
([AP News](https://apnews.com/article/apple-airtags-stalking-lawsuits-e59166988920c4ba1e82956ea85c1677)).
To see the risks from the start, fill in the gaps in this privacy analysis, in
comments. For the unintended recipients, give the one described here, and two
other kinds.

| Question | Answer |
| -- | -- |
| What type of information is shared? | _to be filled in_ |
| Who is the subject of the information? | _to be filled in_ |
| Who is the sender of the information? | The location tag |
| Who are the potential recipients of the information? | **Intended:** the tag's buyer, tracking their own belongings<br/>**Unintended:** _to be filled in_ |
| What principles govern the collection and transmission of the information? | Buying a tag implies consent to tracking one's own things. People tracked without knowing it have not consented to anything. There is little regulation of who can buy or use tags, or of what they must do. Data goes through the worldwide network of phones, with no check that the use is legitimate. |

## Problem 7

What is the last value of `tally`? Trace each change. What happens if you take
out the `global tally` lines, and why?

```python
tally = 0

def points(n: int) -> int:
    global tally
    tally = tally + n
    return tally

def reset() -> int:
    global tally
    tally = 0
    return tally

points(10)
points(5)
reset()
tally
```
