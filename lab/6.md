## Library Loans

A library's loans, with a row per loan. Load them with `pd.read_csv` from
`https://raw.githubusercontent.com/neu-pdi/cs2000-public-resources/refs/heads/main/static/support/library_loans.csv`.
The file starts:

```
book_title,borrower_name,days,loan_type
The Hobbit,Alice Nguyen,7,in-library
1984,Ben Carter,16,home-loan
```

| Column | Meaning |
| -- | -- |
| `book_title` | title of the book |
| `borrower_name` | who borrowed it |
| `days` | how many days it was out |
| `loan_type` | `"in-library"` or `"home-loan"` |

## Problem 1

Add an `overdue_fee` column: each day over 14 costs \$0.25, and a loan of 14
days or fewer has no fee. Write the whole table to `overdue_fees.csv`, with
`to_csv` (as in [Class 27's Practice](/class/27#practice)).

## Problem 2

Files in the wild are often messy: a row might be missing a cell, so it has
fewer cells than the header.

1. Write the loans to a file, `messy_loans.csv`. Open it in the editor, and
   delete one cell from one row, with its comma.
2. Load `messy_loans.csv` with `read_csv`. What happened to that row? Which of
   its columns are wrong, and how can you tell? Does Problem 1 still work on it?
3. Drop the incomplete rows with `dropna`, and write the rest to
   `clean_loans.csv`. Does Problem 1 work on what's left? If not, why not?
