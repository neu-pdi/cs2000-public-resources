### Arithmetic

PLL **evaluates**, or _runs_, what we write: type `4 + 9` at the interactions
prompt and press Enter, and the result, `13`, appears below it. (The Up arrow
brings back what you typed, to edit it.)

- Python follows math's order of operations: `2 + 3*4` is `14`, and
  `(2+3) * 4` is `20`.
- Spaces and parentheses are optional, but help readability. Our
  [Style Guide](/class/style) puts spaces around operators (`2 + 3`), but where
  priorities are mixed, only around the lowest-priority ones, so the spacing
  shows the order: `2 + 3*4`. Add parentheses whenever the order isn't obvious.
- `max(3, 11)` is the larger number, `11`; `min` gives the smaller.

### Expressions

`max` gives back a number, just like `+`, so its result can go anywhere a number
can:

```python
max(3, 11) - 1
(2+4) * min(3, 11)
```

- These produce `10` and `18`: bigger computations are built from smaller ones.
- Try: the number of minutes in a week; the average of the scores 85, 92, and
  78.

### Two Kinds of Numbers

- **Integers** (`int`), like `20`, are always exact.
- **Floating point numbers** (`float`), like `6.0` or `0.25`, have a decimal
  point, and can only represent most numbers approximately (try `0.1 + 0.2`).
- `/` always produces a `float`, even when the answer is whole: `18 / 3` is
  `6.0`.

### Terminology

- **Expression**: a computation in the formal notation of a programming
  language, like `7`, `2 + 3`, or `(2+3) * (4-1)`.
- **Value**: an expression that can't be computed further, like `15` or `6.0`.
- **Program**: a sequence of expressions that you want to run.

### Setting Up

Python is the most widely used programming language in the world, in industry,
science, and education. It was designed for professional programmers, so we use
it through a tool designed for learning: **Python Language Levels** (PLL), an
extension to the vscode.dev editor. PLL runs your Python, shows the results
(including images and tables), and, depending on the _level_ you choose, checks
your programs for common mistakes and explains errors in plainer terms. All
editing this semester happens in the browser:

1. Go to https://vscode.dev.
2. Click the Extensions icon in the left sidebar (the four squares).
   ![VSCode Extensions Icon](/img/vscode-ext.png)
3. Search for **Python Language Levels**.
4. Click **Install**. If it asks you to trust the publisher, do that.
5. If vscode.dev offers to install Microsoft's **Python** extension, **don't**. We are using Python Language Levels, not that one.
6. Open the Command Palette (`Ctrl+Shift+P` on Windows, `Cmd+Shift+P` on a Mac) and run **PLL: Show Interactions**. A **PLL** panel will open at the bottom of the window: this is the **interactions** panel, and it has a prompt at the bottom where you can type Python and press Enter to run it.

   The first time you run something, it can take a little while: PLL is loading Python in the browser. Later runs are faster.

Most of the time we'll write programs in files in the editor, and use the
interactions panel to see results and try things out. Today, we only use the
interactions panel.

## Practice

1. Calculate the area of a rectangle with length 10 and width 3.
1. Calculate its perimeter.
1. Note that many different expressions can produce the same value. Come up with
  three different expressions that all **evaluate** to the value 10. Do all of
  them produce the same value? (Is `10.0` the same as `10`?)
1. Evaluate `0.1 + 0.2`. What do you notice? `float`s can only represent most
  numbers _approximately_, so calculations with them can produce results that are
  very slightly off. `int`s, on the other hand, are always exact.
1. You sell custom T-shirts for \$12 each, and every design needs a one-time \$3
  setup fee. Write an expression for the cost of 5 shirts of one design, then
  one for 7 shirts. Where do you need parentheses, and where are they optional?
1. A poster is 24 by 36 inches, and is priced at \$0.10 per inch of its
  perimeter (twice the sum of its width and height). Write an expression for its
  price. What do you get if you leave out the parentheses around the sum, and
  why?
