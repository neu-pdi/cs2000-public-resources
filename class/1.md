### Motivating Example: Flags

Imagine that you are starting a graphic design company, and want to create
images of flags of different sizes for your customers: say, the flags of Armenia
(in two sizes), Austria, Niger, Colombia, Zambia (on a flagpole), and
Bangladesh:

![The flags of Armenia (in two sizes), Austria, Niger, Colombia, Zambia (on a flagpole), and Bangladesh](/img/day1-flags.svg)

Before writing any code, look at them, and write down answers to:
_What do you notice about the flags?_ and _What do you wonder about them, or
about a program that might produce them?_ Noticing features of data is an
essential skill in computing.

Some flags have the same structure with different colors, and some come in
different sizes. This suggests what we'll need: _numbers_, to compute the
heights of stripes from the size of the flag; _strings_, to describe colors; and
_expressions_, to create and combine images of simple shapes.

### Numbers

Start simple: compute the sum of 3 and 5. We write down the computation, and ask
the computer to _run_ or _evaluate_ it, in a _programming environment_ (ours is
PLL, in vscode.dev). Type `3 + 5` at the interactions prompt, and press Enter:
the result, `8`, appears below it. Similarly, `2 * 6` gives `12`.

What about `3 + 4 * 5`? Try it! Python follows the order of operations from
math, so it multiplies first, giving `23`. To add first, use parentheses:
`(3+4) * 5` is `35` (press Up at the prompt to get back what you typed, and
edit it). Python doesn't require parentheses, or spaces around operators, but
both can make code easier to read. Our [Style Guide](/class/style) puts a space
on each side of an operator, as in `3 + 4`, except that when operators with
different priorities are mixed, only the lowest-priority ones get spaces, so
that the spacing shows the order: `3 + 4*5`, and `(3+4) * 5`. And add
parentheses whenever the order isn't obvious.

To go beyond arithmetic, and find the smaller of two numbers, we'd write
`min(2, 8)`.

### Expressions

`min` gives back a number, just as `+` and `*` do, so we can use its result
anywhere a number is expected:

```python
5 * min(2, 8)
(1+5) * min(2, 8)
```

These produce `10` and `12`. We build up bigger computations from smaller ones,
using operations to combine their results: an _expression_ is a computation
written in a form that Python can evaluate to an answer. Try writing expressions
for each of these:

- subtract 3 from 7, then multiply the result by 4
- subtract 3 from the multiplication of 7 and 4
- the sum of 3 and 5, divided by 2
- the `max` of 10 subtracted from 5, and -20
- 2 divided by the sum of 3 and 5

What did you get when you divided? Python has two kinds of numbers: _integers_
(`int`), like `8`, which are always exact, and _floating point numbers_
(`float`), like `4.0` or `0.25`, which have a decimal point. `/` always produces
a `float`, even when the answer is whole, and `float`s can only represent most
numbers approximately: try `1 / 3`, or `0.1 + 0.2`.

### Terminology

Look at `(3+4) * (5+1)`, which evaluates to `42`. We should name the kinds
of information here:

- **Expression**: a computation written in the formal notation of a programming
  language, like `4`, `5 + 1`, and `(3+4) * (5+1)`.
- **Value**: an expression that can't be computed further (it is its own
  result). So far, the only values we've seen are numbers, like `42` or `4.0`.
- **Program**: a sequence of expressions that you want to run.

### What is Python?

Python is a programming language that is now the most widely used language in
the world, in industry, science, and education. Since Python was designed for
professional programmers, we use it through a tool designed explicitly for
computer science education, and just like designing our programs results in
better programs, designing our tools can help get better results. That tool is
an extension to the VSCode editor called **Python Language Levels** (PLL): it
runs Python for you, shows you results (including images and tables!), and
depending on the _level_ that you choose, checks your programs for common
mistakes, and explains errors in ways that are easier to understand. This allows
us to teach you more than we would be able to otherwise.

### How do we use Python?

All editing, throughout the semester, will happen in the browser, using an
editor called vscode.dev.

1. Go to https://vscode.dev.
2. Click the Extensions icon in the left sidebar (the four squares).

6. Open the Command Palette (`Ctrl+Shift+P` on Windows, `Cmd+Shift+P` on a Mac) and run **PLL: Show Interactions**. A **PLL** panel will open at the bottom of the window: this is the **interactions** panel, and it has a prompt at the bottom where you can type Python and press Enter to run it.

   The first time you run something, it can take a little while: PLL is loading Python in the browser. Later runs are faster.

**Show the editor vs the interactions panel**

Most of the time, we'll write our programs in files in the editor, and use the
interactions panel to see the results, and to try things out. Today, however, we are going to focus on the
interactions panel. We can write arithmetic **expressions** -- i.e., `2 + 3`,
`5 * 4`, `18 / 3`. These **evaluate** to values -- `5`, `20`, `6.0`.

Values are results, expressions are bits of code that can run to produce values.

- Note that `18 / 3` produced `6.0`, not `6`! Python has two kinds of numbers:
  **integers** (`int`), which are whole numbers like `6`, and
  **floating point numbers** (`float`), which have a decimal point, like `6.0`.
  Division with `/` always produces a `float`, even when the answer is a whole number.

- Python does not require spaces around operators: `2+3` works just as well as
  `2 + 3`. Our [Style Guide](/class/style) puts a space on each side of an
  operator, as in `2 + 3`, except that when operators with different priorities
  are mixed, only the lowest-priority ones get spaces, so that the spacing shows
  the order in which they happen: `2*3 + 4`, and `(2+3) * 4`.

- Python follows the usual order of operations from math: `*` and `/` happen
  before `+` and `-`. Note what happens if you write `2 + 3 * 4`, and compare
  it to `(2+3) * 4` and `2 + (3*4)`. (Following our style, the first would be
  written `2 + 3*4`, which makes the order clear.) When it isn't obvious which order will
  happen, add parentheses, so that the next person reading your code doesn't
  have to remember the rules!
