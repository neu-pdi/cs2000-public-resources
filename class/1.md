### Arithmetic

Our _programming environment_, PLL (in vscode.dev), **evaluates**, or _runs_,
what we write: type `3 + 5` at the interactions prompt and press Enter, and the
result, `8`, appears below it. (Press Up to get back what you typed, and edit it.)

- Python follows math's order of operations: `3 + 4 * 5` is `23`, and
  `(3+4) * 5` is `35`.
- Spaces and parentheses are optional, but help readability. Our
  [Style Guide](/class/style) puts spaces around operators (`3 + 4`), but where
  priorities are mixed, only around the lowest-priority ones, so the spacing
  shows the order: `3 + 4*5`. Add parentheses whenever the order isn't obvious.
- `min(2, 8)` is the smaller number, `2`; `max` gives the larger.

### Expressions

`min` gives back a number, just like `+`, so its result can go anywhere a number
can:

```python
5 * min(2, 8)
(1+5) * min(2, 8)
```

- These produce `10` and `12`: bigger computations are built from smaller ones.
- Try: "subtract 3 from 7, then multiply by 4"; "2 divided by the sum of 3 and 5".

### Two Kinds of Numbers

- **Integers** (`int`), like `8`, are always exact.
- **Floating point numbers** (`float`), like `4.0` or `0.25`, have a decimal
  point, and can only represent most numbers approximately (try `0.1 + 0.2`).
- `/` always produces a `float`, even when the answer is whole: `8 / 2` is `4.0`.

### Terminology

- **Expression**: a computation in the formal notation of a programming
  language, like `4`, `5 + 1`, or `(3+4) * (5+1)`.
- **Value**: an expression that can't be computed further, like `42` or `4.0`.
- **Program**: a sequence of expressions that you want to run.

### What is Python?

Python is a programming language that is now the most widely used language in
the world, in industry, science, and education. Since Python was designed for
professional programmers, we use it through a tool designed explicitly for
computer science education, and just like designing our programs results in
better programs, designing our tools can help get better results. That tool is
an extension to the VSCode editor called **Python Language Levels** (PLL): it
runs Python for you, shows you results (including images and tables!), and
depending on the _level_ that you choose, checks your programs for common
mistakes, and explains errors in ways that are easier to understand. This allows
us to teach you more than we would be able to otherwise.

### How do we use Python?

All editing, throughout the semester, will happen in the browser, using an
editor called vscode.dev.

1. Go to https://vscode.dev.
2. Click the Extensions icon in the left sidebar (the four squares).
   ![VSCode Extensions Icon](/img/vscode-ext.png)
3. Search for **Python Language Levels**.
4. Click **Install**. If it asks you to trust the publisher, do that.
5. If vscode.dev offers to install Microsoft's **Python** extension, **don't**. We are using Python Language Levels, not that one.
6. Open the Command Palette (`Ctrl+Shift+P` on Windows, `Cmd+Shift+P` on a Mac) and run **PLL: Show Interactions**. A **PLL** panel will open at the bottom of the window: this is the **interactions** panel, and it has a prompt at the bottom where you can type Python and press Enter to run it.

   The first time you run something, it can take a little while: PLL is loading Python in the browser. Later runs are faster.

programs in files in the editor, and use the interactions panel to see the
