## Notes (review before class)
### A Template, Abstracted

[Class 27](/class/27) abstracted two functions by comparing them. A template is
already the outline of _every_ function on its data, so abstracting the
template itself gives one function that all of them can be written with. Here
is the list template ([Class 22](/class/22)):

```python
def _list_temp(lst: list) -> ...:
    match lst:
        case []:
            return ...
        case [f, *r]:
            ...
            f
            ...
            _list_temp(r)
            ...
            return ...
```

A function from it fills in two places: what to give for `[]`, and how to
combine `f` with what the recursive call gives for `r`. `total_boxes`
([Class 22](/class/22)) gives `0`, and adds `f` to the answer for `r`;
`count_orders` gives `0`, and adds `1`. Making both places parameters gives a
**fold**: a value, `base`, for the empty list, and a function, `combine`, which
takes the first element and the answer for the rest:

```python
def fold[T, R](combine: Callable[[T, R], R], base: R, lst: list[T]) -> R:
    """base, if lst is empty; otherwise, combine on lst's first element and
    the fold of the rest"""
    match lst:
        case []:
            return base
        case [f, *r]:
            return combine(f, fold(combine, base, r))
```

- `T` is the type of the elements, and `R` the type of the answer.
  `combine: Callable[[T, R], R]` takes an element and an answer for the rest of
  the list, and gives the answer for the whole list.
- `base` is an `R` too: it is the answer for an empty list.

[Class 22](/class/22)'s two functions on orders, as calls of `fold`:

```python
def total_boxes(orders: list[int]) -> int:
    """the total number of boxes in orders"""
    def add(boxes: int, total: int) -> int:
        return boxes + total
    return fold(add, 0, orders)

def count_orders(orders: list[int]) -> int:
    """the number of orders in orders"""
    def one_more(boxes: int, count: int) -> int:
        return 1 + count
    return fold(one_more, 0, orders)

def test_total_boxes_of_no_orders():
    assert total_boxes([]) == 0

def test_total_boxes_of_three_orders():
    assert total_boxes([2, 4, 1]) == 7

def test_count_orders_of_no_orders():
    assert count_orders([]) == 0

def test_count_orders_of_three_orders():
    assert count_orders([2, 4, 1]) == 3
```

- Each helper's second parameter is the answer for the rest of the list, so it
  is named for what it is: `total`, `count`.
- `one_more` doesn't use `boxes`: counting doesn't need the elements.

### Which Functions Are Folds?

A function is a call of `fold` when its body is the list template with nothing
more: one answer for `[]`, and an answer for `[f, *r]` made from `f` and the
recursive call's answer for `r`.

- `add_till_zero` ([Class 23](/class/23)) is one. Its helper gives `0` when the
  element is `0`, and the element plus the answer for the rest otherwise. (A
  fold still finds the answer for the rest first, so it goes through the whole
  list, even where `add_till_zero` didn't need to.)
- `insert_sorted` ([Class 23](/class/23)) isn't: when `n` goes in front, its
  answer is `[n] + lst`, which needs the rest itself, not the answer for it.
- `my_filter` and `my_map` ([Class 27](/class/27)) are folds too: try writing
  them that way (in the Practice).

### The Tree Template, Abstracted

The same works for any template. A `BST`'s ([Class 26](/class/26)) has one
answer for an `EmptyLeaf()`, and, for a `Node`, a combination of its key, its
value, and the two recursive calls' answers:

<!-- python setup
@dataclass
class EmptyLeaf:
    pass

@dataclass
class Node:
    key: int
    val: str
    left: BST
    right: BST

BST = EmptyLeaf | Node

BST0 = EmptyLeaf()
BST1 = Node(1, "hello", BST0, BST0)
BST2 = Node(5, "bye", BST1, BST0)
BST3 = Node(6, "bye", BST2, Node(10, "cs2000", BST0, BST0))
-->

```python
def bst_fold[R](combine: Callable[[int, str, R, R], R], base: R, bst: BST) -> R:
    """base, if bst is an EmptyLeaf; otherwise, combine on its key, its value,
    and the folds of its two subtrees"""
    match bst:
        case EmptyLeaf():
            return base
        case Node():
            return combine(bst.key, bst.val, bst_fold(combine, base, bst.left),
                           bst_fold(combine, base, bst.right))
```

- Only the answer's type is a variable: a `BST`'s keys are always `int`s, and
  its values `str`s, so those stay in the Signature.
- `combine` takes four arguments, one per part of a `Node`, with the subtrees'
  answers in place of the subtrees.

`height` ([Class 26](/class/26)), as a call of it:

```python
def height(bst: BST) -> int:
    """the number of nodes on the longest path from the root of bst to an
    EmptyLeaf"""
    def taller(k: int, v: str, left_height: int, right_height: int) -> int:
        return 1 + max(left_height, right_height)
    return bst_fold(taller, 0, bst)

def test_height_of_an_empty_tree():
    assert height(BST0) == 0

def test_height_of_one_node():
    assert height(BST1) == 1

def test_height_of_two_nodes():
    assert height(BST2) == 2

def test_height_of_three_nodes():
    assert height(BST3) == 3
```

### Designing with Abstractions

With `my_filter` and `my_map` ([Class 27](/class/27)) and `fold`, a function on
a list often needs no template of its own. The shape of its answer picks the
abstraction, and the work is in the helper:

| The answer | The abstraction | Its helper says |
| --- | --- | --- |
| some of the elements | `my_filter` (or Python's `filter`) | whether to keep an element |
| each element, changed | `my_map` (or Python's `map`) | the new value of an element |
| one value, from all of them | `fold` | how one element combines with the answer for the rest |

The rest of the recipe is the same: the Signature, Docstring, and Examples come
first, and the Body is a call, with its helper. For example, the length of the
longest word in a list, or `0` if there are none: one value from all the
elements, so `fold`:

```python
def longest_length(words: list[str]) -> int:
    """the number of letters in the longest word in words (0 if words is empty)"""
    def longer(w: str, longest: int) -> int:
        return max(len(w), longest)
    return fold(longer, 0, words)

def test_longest_length_of_no_words():
    assert longest_length([]) == 0

def test_longest_length_of_three_words():
    assert longest_length(["oak", "maple", "elm"]) == 5
```

## Live

A worksheet, in pairs, alternating problems. For each function on the sheet,
with its Signature, Docstring, and Examples, one of you picks the abstraction
by the answer's shape and writes the body as a call of it, with its helper; the
other checks it against the examples, by hand. Then you swap for the next one.
