## Recap (5 mins)

- Today we will continue practicing with `for` loops (so our files should still start with `#level intermediate`).
- Most exercises come in pairs: one function with the
  [loop template](/class/recipe#template-loops), building a list
  ([Class 15](/class/15)), then the same function with the
  [list template](/class/recipe#template-lists) ([Class 14](/class/14)). The
  two have the same Signature, Docstring, and Examples: only the Template and
  the Body change. So write the Examples once, and run both versions against
  them.

## Class Exercises (50 mins)

1. Design a function `my_doubles` that takes a list of numbers and returns a new list
  where each element is twice what the corresponding element was in the original list.
  (Loop template, building.)
1. Re-implement the same function as `my_doubles_map` using the built-in `map`. Which implementation do you find clearer?
  (List template, each one changed.)
1. Design `my_string_lens`, which takes a list of strings and returns a new
  list where each element is the length of the string in the corresponding
  position in the input list. (Loop template, building.)
1. Re-implement the same function as `my_string_lens_map` using the built-in `map`. Which implementation do you find clearer?
  (List template, each one changed.)
1. Design `my_pos_nums`, which takes a list of numbers and returns a new list
  that contains only those numbers in the original list that are positive.
  (Loop template, building, with an `if`.)
1. Re-implement the same function as `my_pos_nums_filter` using the built-in `filter`. Which implementation do you find clearer?
  (List template, fewer elements.)
1. Design `my_alternating`, which takes a list of any element and returns a new
  list that contains every other element -- i.e., keep the first, skip the
  second, etc. Note: you may need _two_ variables that change for this one -- one to
  contain the result, as normal, but the other to keep track of the alternation.
1. Can you express `my_alternating` using either `map` or `filter`? Which
  template fits it, and why doesn't the list template?
1. Design `my_running_sum`, that takes a list of numbers and returns a list where
  each position contains a sum of the numbers in the original list up to the
  corresponding position. i.e., `my_running_sum([1, 2, 3]) == [1, 3, 6]`.
1. Can you express `my_running_sum` using either `map` or `filter`? Which
  template fits it?

## Wrap-up (5 mins)

- `for` loops are very expressive, but sometimes harder to understand than
  using built-in operations like `filter` or `map`.
- Template of the day: the [list template](/class/recipe#template-lists) when
  one of its shapes fits the answer, and the
  [loop template](/class/recipe#template-loops) for everything else, like
  `my_alternating` and `my_running_sum`.
