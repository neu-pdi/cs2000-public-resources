## Notes (review before class)

Nothing new to read today: it's practice with the `for` loops of
[Class 15](/class/15), beside the list template of [Class 14](/class/14) (so
files still start with `#level intermediate`).

- Most problems come in pairs: one function with the
  [loop template](/class/recipe#template-loops), building a list, then the same
  function with the [list template](/class/recipe#template-lists). The two have
  the same Signature, Docstring, and Examples: only the Template and the Body
  change. So write the Examples once, and run both versions against them.
- Some answers don't fit any shape of the list template. Then the loop template
  is the one to use, and its `result` may need a second changing variable to
  remember something from the trip before.

## Live

Mirror pairs. For each problem, you and your partner write the Signature,
Docstring and Examples together. Then one of you writes the `for` loop version
and the other the `map` or `filter` version, each on your own sheet, and you
check each other's by tracing it on your shared Examples. You swap roles for
the next problem.

## Practice

1. Design `in_hours`, which takes a list of lengths of time, in minutes, and
  gives a new list of the same lengths in hours. (Loop template, building.)
1. Re-implement it as `in_hours_map`, using `map`. Which do you find clearer?
  (List template, each one changed.)
1. Design `initials`, which takes a list of names and gives a list of each
  name's first letter. (`"Priya"[0]` is `"P"`: square brackets work on strings
  as on lists.) Then re-implement it as `initials_map`.
1. Design `passing_scores`, which takes a list of exam scores and gives just the
  scores of 60 or more, in order. (Loop template, building, with an `if`.) Then
  re-implement it as `passing_scores_filter`, with `filter`. (List template,
  fewer elements.)
1. Design `differences`, which takes a list of numbers and gives a list of each
  number minus the one before it: `differences([3, 5, 4, 8])` is `[2, -1, 4]`.
  You'll need _two_ variables that change: the result, as usual, and the
  previous number. Can you express it with `map` or `filter`? Which template fits
  it, and why doesn't the list template?
1. Design `running_max`, which gives, at each position, the largest number so
  far: `running_max([3, 1, 4, 1, 5])` is `[3, 3, 4, 4, 5]`. Can you express it
  with `map` or `filter`? Which template fits it?
1. In each pair you wrote, which version would you rather read, and which
  would you rather change? `for` loops can do more, but a built-in like `filter`
  or `map` says at a glance which shape the answer has.
